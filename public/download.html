📋 Setup Instructions

  1. Download and extract the ZIP file
  2. Open the folder in VS Code: code laxchat
  3. Open terminal in VS Code and run: npm install
  4. Run: npm run dev
  5. Open http://localhost:5173 in your browser
  6. 💡 Open multiple tabs to test chatting between users!
